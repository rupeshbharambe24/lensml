lensml.

An AI agent that supervises your PyTorch training runs. Detects bugs, proposes libcst-level patches, resumes from checkpoint.

View on GitHub Build log

30-second install

pip install lensml
lensml dashboard &        # localhost:8000
# in your training script:
import lensml
lensml.watch(model, optimizer)

What you get

Live telemetry

Forward hooks + optimizer.step interception stream loss, grad-L2, activation stats to a local dashboard with <2% overhead.

8 detectors

Stream consumers fire on exploding gradients, dead ReLUs, lr too high, missing normalize, model.eval() not called, bad init, vanishing grad, dataloader bottlenecks.

libcst patches

The agent proposes a unified diff. You press y. lensml commits the patch to a session branch, checkpoints state, restarts your script.

Three integrations

Raw PyTorch, PyTorch Lightning callbacks, HuggingFace Trainer callbacks. One lensml.watch(...) per loop.

Free LLM routing

LiteLLM fallback chain across Groq / Cerebras / Gemini / OpenRouter / Mistral. Plus a Plan-C local privacy-mode toggle.

Reproducible bench

lensml-bench: 8 deterministic fixtures, subprocess grader, JSON cache, side-by-side LLM-only baseline arm.
